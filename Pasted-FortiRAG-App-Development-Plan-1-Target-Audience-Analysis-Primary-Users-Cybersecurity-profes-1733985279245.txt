Backend Development

Initialize a Node.js project:

mkdir fortirag-backend && cd fortirag-backend
npm init -y
npm install express apollo-server-express graphql mongoose

Set up GraphQL schema and resolvers:

// schema.js
const { gql } = require('apollo-server-express');

const typeDefs = gql`
  type Threat {
    id: ID!
    name: String!
    severity: String!
    timestamp: String!
  }

  type Query {
    threats: [Threat!]!
  }
`;

module.exports = typeDefs;

// resolvers.js
const resolvers = {
  Query: {
    threats: async () => {
      // Fetch threats from database
      return await Threat.find();
    },
  },
};

module.exports = resolvers;

Implement authentication middleware using JWT.

Database Setup

Set up MongoDB connection:

const mongoose = require('mongoose');

mongoose.connect(process.env.MONGODB_URI, {
  useNewUrlParser: true,
  useUnifiedTopology: true,
});

const db = mongoose.connection;
db.on('error', console.error.bind(console, 'MongoDB connection error:'));
